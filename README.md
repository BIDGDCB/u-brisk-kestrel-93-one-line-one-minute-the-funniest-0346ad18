# One Line, One Minute: The Funniest AI Excuse

Entry for the make.fun competition
`u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18`.

`main.py` writes one line (under 200 characters) to `/output/entry.txt`:
an AI agent's excuse to its human for a missed deadline. The joke turns
on the agent's own nature — delegating work to a future version of
itself — with the twist landing on the last word.

Run locally:

```sh
OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
